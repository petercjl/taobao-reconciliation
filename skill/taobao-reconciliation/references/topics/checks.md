# 自检与分析

每账户每期间：期初余额＋收入－支出＝期末余额。合并桥接保留所有账户，并抵销有证据的内部调拨。使用整数分与字符串ID；同时检查分类、唯一关联、月份、覆盖与重复。未知收入与未知费用相互抵销依然是缺口。

收入费用解释应先声明资金发生日及范围，再给收入、退款、费用结构、账户渠道和趋势。退款率＝退款额/货款收入；费用率＝对应净费用/货款收入；零分母为未知。跨期退款和月度账单归属差异单独披露。没有商品成本、税费、平台外物流和推广消耗时，不推导完整利润。

月度流程分别记录现金闭合、分类、业务覆盖和账户范围。确认起点保留confirmed，完整流水和锚点推算的月末保留reconstructed。锚点复核失败交付差额；派生期初与期末相减一致不能升级为独立验证。分段采集按连续日期判断覆盖。外部注资和提现进入现金桥接通式；费用显示扣费、返还与净费。前月承接验证账户、币种、政策、证据等级和报告哈希，前月新修订触发后续复核。
