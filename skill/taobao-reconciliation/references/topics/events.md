# 事件分类

淘宝业务账单按billCycle归入账单月份。其bizDate可能是更早的订单或交易发生时间，不能据此把本月扣费明细筛到上个月。现金报告仍以账户实际入账时间为准，两个时间都保留以解释跨月关系。

资金主线每一流水只计一次；多账单描述同一事件时建立关联。平台货款净结算、退款、服务费与收款渠道要保留原始语义；未识别业务码保持 unknown。

保证金缴存和自动补足是内部资金移动。赔付或退款可能经过保证金拨付到支付宝后再次支出，需要按完整链路识别镜像，先保持各账户流水完整，再决定合并分类。同额或同时间只能形成候选，不直接配对。

品牌新享费用/退费按营销托管归类，费用净额保留退款的反方向金额。消费积分与汇总账单作辅助，不自动叠加现金收入。外部注资和提款单列。

已验证的自动关联要求平台业务码符合保证金缴存或扣除转移语义、同订单同资金日、两账户金额相反且候选唯一。缺订单的初始缴存由应用核对两侧平台业务码、真实对方账户和原始凭据后显式写 transferPairs。用户指定关联优先于自动关联。

平台按子订单列明细而资金按父订单合并时，保留子订单集合，按订单组核对总额；不把一笔合并收款虚构成逐子订单现金流水。月度消费者体验服务费按账期保留，与现金发生日可能跨期，单独核查而不强行凑平。

消费者体验服务费月账单不含订单号时，以完整自然月的同类扣费减退费核对账单金额，保留月度关联而不虚构逐笔订单关系；月份范围不足或金额不等仍列为缺口。交易订单状态用于解释待收款与退款，单独作为辅助事实，不重复增加现金收入。
