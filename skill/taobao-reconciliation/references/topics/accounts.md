# 账户范围

资金账户与业务账单是独立观察方向。三个账户总额分别是支付宝、聚合结算和现金保证金；可用与冻结只是同一账户组成，不能重复加总。保证金保险保额不是现金余额。提现和外部注资需明确边界，跨账户调拨要关联后抵销。推广余额属于另一个账户范围。

历史月结余额 official_statement 和当前账户快照 account_snapshot 是独立证据；最后流水后的余额 ledger_after_balance 只能诊断，不能填补期初或期末自检。未显示余额或空账单保留 null。

订单核对分为平台订单主账、供应商发货/退货、结算账单、账户资金四个事实方向。用主子订单、真实运单和金额做关联；先区分未支付关闭、付款后全退、待确认收货、结算后退款、当日入账尚未出结算账单。发货表缺少金额或订单状态时，只证明发货与数量范围。平台“实收款”展示字段在待付款和关闭订单上也可能有值，不能直接作为资金实收。

官方字段说明可参考 [淘系对账说明](https://developer.alibaba.com/docs/doc.htm?articleId=121793&docType=1&treeId=826)：M 为主单、S 为子单，交易账单与资金账单分别表示交易状态和账户变动。费率、更新时间及本店余额以本次平台实际证据为准。
